# PART I — PRODUCT VISION

## 1. The concept

The student becomes the producer and director of an independent mountain bike film.

Their mission is to create a cinematic freeride MTB film featuring a talented rider, an incredible riding location and a professional production crew.

They have:
- A rider to feature.
- A filming location.
- A cinematographer.
- A drone operator.
- A camera and equipment package.
- A limited production budget.
- A shooting schedule.
- A final editing deadline.

Their job is to organize the production, calculate costs, understand the relationships between different quantities, manage resources and get the film ready for release.

Use the real-world culture of mountain bike filmmaking as inspiration.

Reference:
- Anthill Films.
- Red Bull Media House productions.
- Behind-the-scenes Rampage filmmaking.
- Independent freeride edits.
- Dirt-jump and slopestyle film projects.
- Drone and FPV filming.
- Cinematic downhill film production.

### Central learning philosophy

Linear equations and functions are tools for modeling relationships.

Students should see how filmmakers use mathematical relationships to understand budgets, schedules, resource consumption and production targets.

The film-production storyline creates a compelling reason to write equations, interpret slope, identify intercepts, graph relationships and understand functions.

## 2. Important distinction from previous Mathlete labs

This lab must have a different identity from:
- The Dream Line Project — park construction.
- The Dream Line Goes Pro — MTB engineering.
- Map the Line — GPS mapping and ride data.

Frame the Line is about mountain bike media and filmmaking.

The student is working behind the camera, not building a park or riding a trail.

This creates an entirely different environment within the Mathlete MTB universe.

## 3. Educational objectives

The experience must directly teach all six Algebra 1 topics.

### A. Writing Linear Equations
- Write equations from slope and a point.
- Write equations from two points.
- Write equations from tables.
- Write equations from graphs.
- Write equations from real-world descriptions.

### B. Slope-Intercept Form
- Identify slope and y-intercept in `y = mx + b`.
- Explain the meaning of m and b in context.
- Rewrite equations into slope-intercept form.

### C. Point-Slope Form
- Write equations using `y - y1 = m(x - x1)`.
- Convert between point-slope and slope-intercept forms.
- Select the most useful form for a problem.

### D. Graphing Linear Equations
- Graph lines using slope and y-intercept.
- Graph using x- and y-intercepts.
- Graph horizontal and vertical lines.
- Interpret graphs in context.

### E. Domain and Range
- Find domain and range from graphs, tables and ordered pairs.
- Determine reasonable inputs for real-world models.
- Express domain and range using inequalities and interval notation.

### F. Function Notation
- Determine whether a relation is a function.
- Evaluate functions using `f(x)` notation.
- Interpret function outputs in real-world situations.

# PART III — THE SIX LEARNING STAGES

# STAGE 01: PLAN THE PRODUCTION
## Writing Linear Equations

### 7. Mission

The student becomes the executive producer.

Before filming begins, they need to establish a production budget.

There are fixed costs, daily filming expenses and a total production plan.

Their job is to create a mathematical model describing the cost of the film.

This is the introduction to writing linear equations from different representations.

### Core production model

Introduce a fictional production budget:

- Initial pre-production and equipment costs: $1,800.
- Additional filming cost: $420 per shoot day.

Define:

- `d` = filming days.
- `C` = total production cost.

The relationship is:

`C = 420d + 1800`

Clearly explain:
- The $1,800 is the fixed initial cost.
- The $420 is added for each filming day.
- The total cost changes depending on the number of shoot days.

These are fictional classroom production credits expressed in dollars, not professional film-industry rates.

### Activity 1 — Write an Equation from a Description

Present the producer's description:

"The production requires $1,800 in initial expenses, and every shoot day adds $420 to the total."

Ask students to construct the equation.

Correct answer:

`C = 420d + 1800`

Provide interactive mathematical building blocks:
- C
- d
- 420
- 1800
- Addition.
- Multiplication.
- Subtraction.

Students arrange the components to construct the equation.

The interface should visually highlight:
- Fixed production expense.
- Daily filming expense.
- Total cost.

### Activity 2 — Write an Equation from Slope and a Point

Introduce a different situation.

The producer knows:
- The daily cost is $420.
- After three shoot days, the project has cost $3,060.

Ask the student to write an equation.

Known:
- `m = 420`
- Point `(3,3060)`

Start with point-slope form or slope-intercept form.

Using the supplied slope and point:

`C = 420d + b`

Substitute:

`3060 = 420(3) + b`

`3060 = 1260 + b`

`b = 1800`

Therefore:

`C = 420d + 1800`

Require students to complete the missing steps rather than immediately presenting the solution.

### Activity 3 — Write an Equation from Two Points

Provide two production-cost checkpoints.

| Filming days | Total cost |
|---:|---:|
| 1 | $2,220 |
| 5 | $3,900 |

Ask students to calculate the slope:

`m = (3900 - 2220) / (5 - 1)`

`m = 1680 / 4`

`m = 420`

Then substitute either point to calculate the y-intercept.

Correct equation:

`C = 420d + 1800`

Teach students how two points define a unique line when their x-values are different.

### Activity 4 — Write an Equation from a Table

Show:

| Shoot days (d) | Production cost (C) |
|---:|---:|
| 0 | 1800 |
| 1 | 2220 |
| 2 | 2640 |
| 3 | 3060 |
| 4 | 3480 |
| 5 | 3900 |

Ask:
- What is the starting cost?
- How much does the cost increase per day?
- What is the equation?

Students must identify the constant rate of change.

### Activity 5 — Write an Equation from a Graph

Display a production-cost graph.

The graph should have:
- x-axis: filming days.
- y-axis: production cost in dollars.
- y-intercept at 1800.
- Slope of 420.

Students click two points and use them to construct the equation.

### Activity 6 — Production Model Challenge

Present a variety of film-production descriptions.

Examples:
- Fixed camera package rental plus a daily filming fee.
- Travel cost plus a per-day lodging expense.
- Editing service retainer plus a cost per editing hour.
- Fixed location preparation plus recurring daily production costs.

Students translate descriptions into linear equations.

Do not overcomplicate the scenarios.

The objective is to understand how real-world descriptions become mathematical models.

### Stage completion

Award:

`EXECUTIVE PRODUCER` badge.

# STAGE 02: UNDERSTAND THE BUDGET
## Slope-Intercept Form

### 8. Mission

The student needs to understand exactly how the production budget grows as filming continues.

They will work with the equation:

`C = 420d + 1800`

Explain that this is slope-intercept form:

`y = mx + b`

Where:
- `m` is the slope.
- `b` is the y-intercept.

### Activity 1 — Identify the Production Slope

Highlight the slope:

`m = 420`

Explain:

For every additional shoot day, the modeled production cost increases by $420.

Visually represent the budget increasing over time.

Add a slider that lets students increase the shoot days and see the total budget change.

### Activity 2 — Identify the Initial Production Cost

Highlight:

`b = 1800`

Explain:

When no filming days have occurred, the project has already incurred $1,800 in initial production expenses.

Show the point:

`(0,1800)`

Animate the fixed production cost appearing on the budget dashboard before filming begins.

### Activity 3 — The Production Budget Explorer

Create an interactive graph.

The student can change:
- Daily production cost.
- Initial production cost.
- Number of filming days.

Update the equation and graph dynamically.

For example:

`C = 500d + 2000`

Compare against:

`C = 300d + 2000`

Ask:

"Which production model becomes more expensive more quickly?"

Students should identify the line with the greater slope.

Then compare:

`C = 420d + 1800`

`C = 420d + 2500`

Explain:
- Same slope.
- Different y-intercepts.
- Different starting costs.

### Activity 4 — Rewrite the Equation

Give students equations that are not initially written in slope-intercept form.

Example:

`2C - 840d = 3600`

Rearrange:

`2C = 840d + 3600`

`C = 420d + 1800`

Ask the student to identify the slope and intercept.

Include manageable examples that reinforce rearranging equations.

### Activity 5 — The Producer's Challenge

Present a collection of equations and ask students to identify:
- Slope.
- Y-intercept.
- Meaning of the slope in context.
- Meaning of the intercept in context.

Include examples where the variables have different meanings.

### Stage completion

Award:

`BUDGET DIRECTOR` badge.

# STAGE 03: CALCULATE MID-PROJECT COSTS
## Point-Slope Form

### 9. Mission

Filming is underway.

The producer receives a production update partway through the project.

They know the current budget and the rate at which expenses increase, but need to calculate how costs will change from this point forward.

This creates a natural reason to use point-slope form.

### Activity 1 — The Production Checkpoint

The film has reached its third shoot day.

The total production cost is $3,060.

Every additional shoot day costs $420.

The student needs to construct an equation based on this checkpoint.

Known:
- `d1 = 3`
- `C1 = 3060`
- `m = 420`

Introduce point-slope form:

`y - y1 = m(x - x1)`

Substitute:

`C - 3060 = 420(d - 3)`

This is the correct point-slope equation.

Show the student how the equation represents the production budget starting from a known point.

### Activity 2 — Convert to Slope-Intercept Form

Ask students to convert:

`C - 3060 = 420(d - 3)`

Distribute:

`C - 3060 = 420d - 1260`

Add 3060:

`C = 420d + 1800`

Show the connection between the two equation forms.

The same linear relationship can be represented in multiple ways.

### Activity 3 — Choose the Best Equation Form

Create scenarios where different forms are more convenient.

**Situation A**

The production cost increases by $420 per filming day, starting with $1,800.

Best form:

`C = 420d + 1800`

**Situation B**

At day three, the total is $3,060 and each additional filming day costs $420.

Best form:

`C - 3060 = 420(d - 3)`

Ask the student to decide which form communicates the information most directly.

### Activity 4 — Write Equations from Different Checkpoints

Provide new point-and-slope challenges.

Examples:

1. An editing project costs $1,200 after 4 hours of editing. The hourly cost is $150.

`E - 1200 = 150(h - 4)`

2. A camera storage card has 400 GB available after 5 hours of filming. Storage availability decreases by 40 GB per hour.

`S - 400 = -40(h - 5)`

3. An editing package uses 15 production minutes per hour of editor time, with 60 minutes of initial work already completed.

`M - 60 = 15(h - 0)`

The third example is a simplified production-planning model.

Ask students to:
- Identify the known point.
- Identify the slope.
- Construct point-slope form.
- Convert to slope-intercept form if requested.

### Activity 5 — Point-Slope Equation Builder

Create a visual builder where students select:
- The slope.
- The x-coordinate.
- The y-coordinate.

The system constructs the point-slope equation with missing components for the student to complete.

Then let them choose whether to convert to slope-intercept form.

### Stage completion

Award:

`PRODUCTION COORDINATOR` badge.

# STAGE 04: BUILD THE PRODUCTION GRAPH
## Graphing Linear Equations

### 10. Mission

The student is now responsible for visualizing the film's production data.

They need to create graphs showing costs, equipment capacity and filming schedules.

This stage should contain the most advanced graphing interactions in the experience.

### Activity 1 — Graph the Production Budget

Start with:

`C = 420d + 1800`

The student must graph the equation using:
- Slope.
- Y-intercept.

First plot:

`(0,1800)`

Then use the slope:

`420 = 420/1`

Move right one day and up $420.

Plot:
- `(1,2220)`
- `(2,2640)`
- `(3,3060)`
- `(4,3480)`

Connect the points.

Animate the budget line developing as students add points.

Require the student to interpret the graph.

### Activity 2 — The Memory Card Capacity Challenge

Introduce a production constraint.

The camera crew begins with 600 GB of free memory card capacity.

Their cameras use 40 GB of space for every hour of footage recorded.

Define:

- h = filming hours.
- S = remaining free storage in GB.

Equation:

`S = 600 - 40h`

Explain:
- Y-intercept is 600 GB.
- Slope is -40 GB per hour.

The student must graph the line.

Calculate the intercepts.

Y-intercept:

`(0,600)`

X-intercept:

`600 - 40h = 0`

`h = 15`

X-intercept:

`(15,0)`

Interpretation:

After 15 hours of recording at the modeled storage rate, the available storage reaches zero.

This is a simplified classroom model and does not account for variable codecs, frame rates, audio or file compression.

### Activity 3 — Graph from Intercepts

Provide equations in standard form and ask students to identify x- and y-intercepts.

Example:

`2h + S = 600`

X-intercept:

`(300,0)` would be incorrect if h represents hours; solve carefully:

When S = 0:

`2h = 600`

`h = 300`

Y-intercept:

When h = 0:

`S = 600`

This is a deliberately different fictional equipment model with a rate of 2 storage units per filming hour.

Use clear variable units.

Include a range of standard-form equations with simpler integer intercepts.

Require students to plot both intercepts and connect them.

### Activity 4 — Horizontal Lines

Introduce:

`y = 700`

Context:

A fictional equipment rental package has a fixed modeled fee of 700 credits, regardless of the number of filming hours.

Explain:
- Slope equals zero.
- The output does not change as the input changes.
- The line is horizontal.

Ask the student to identify the y-intercept and graph the line.

### Activity 5 — Vertical Lines

Introduce:

`x = 4`

Context:

The filming schedule marks the fourth shoot day as the scheduled equipment handover point.

Explain:
- Every point has x = 4.
- The y-value can vary.
- The line is vertical.
- Its slope is undefined.

Use this as a bridge into function notation: a vertical line does not represent y as a function of x because one x-value corresponds to multiple y-values.

Do not confuse a vertical reference marker with a normal production-cost function.

### Activity 6 — Graph Interpretation Challenge

Show graphs and ask students to determine:
- Slope.
- Y-intercept.
- X-intercept.
- Whether the line is increasing, decreasing or constant.
- What the line means in the production scenario.

Require students to graph equations from slope-intercept form, intercepts and tables.

### Stage completion

Award:

`GRAPHING EDITOR` badge.

# STAGE 05: MANAGE THE PRODUCTION LIMITS
## Domain and Range

### 11. Mission

The production team has a limited number of filming days, editing hours and memory storage capacity.

The student must understand which input values make sense and what output values are possible.

### Activity 1 — The Production Budget Domain

Return to:

`C(d) = 1800 + 420d`

The project has been approved for a maximum of eight shoot days.

For this instructional model, costs are prorated for partial days.

Ask:

"What values of d make sense for this production?"

Domain:

`0 ≤ d ≤ 8`

Interval notation:

`[0,8]`

Range:

At zero days:

`C(0) = 1800`

At eight days:

`C(8) = 5160`

Therefore:

`1800 ≤ C ≤ 5160`

Interval notation:

`[1800,5160]`

Explain:
- Domain represents possible shoot-day inputs.
- Range represents possible production-cost outputs.

Also introduce the distinction between continuous billing models and whole-day schedules.

If the production only allows complete shooting days, the domain is:

`{0,1,2,3,4,5,6,7,8}`

The possible costs are:

`{1800,2220,2640,3060,3480,3900,4320,4740,5160}`

Teach that real-world domains depend on the scenario and should not be chosen automatically.

### Activity 2 — Memory Card Domain and Range

Use:

`S(h) = 600 - 40h`

The storage card begins with 600 GB free.

Recording cannot continue beyond the point where available storage reaches zero.

Domain:

`0 ≤ h ≤ 15`

Range:

`0 ≤ S ≤ 600`

Visually show the storage bar decreasing as the student increases filming hours.

At 15 hours, the storage is full.

### Activity 3 — Read Domain and Range from a Graph

Display several different production graphs.

Require the student to identify:
- Minimum and maximum x-values.
- Minimum and maximum y-values.
- Included and excluded endpoints.
- Continuous intervals.
- Discrete data values.

Use open and closed circles where appropriate.

Show how the graph's endpoints determine the domain and range.

### Activity 4 — Domain and Range from Tables and Ordered Pairs

Present tables showing:
- Shoot hours and total budget.
- Editing hours and remaining storage.
- Number of final clips and their combined runtime.
- Filming day and number of approved shots.

Ask the student to identify the set of input values and output values.

Use repeated output values to reinforce that a function can have multiple inputs with the same output.

### Activity 5 — Build a Realistic Production Model

Let students select:
- Maximum shoot days.
- Initial production expense.
- Daily cost.
- Maximum storage.

The system generates a linear model and asks them to choose a reasonable domain and range.

The student must explain why values outside the selected range would not make sense in the project.

Award:

# STAGE 06: DIRECT THE FILM
## Function Notation

### 12. Mission

The film is almost finished.

The student is now responsible for evaluating production functions and understanding how inputs produce outputs.

This stage should make function notation feel like a useful way to communicate information about the project.

### Activity 1 — What Is a Function?

Introduce:

`C(d) = 1800 + 420d`

Explain:

The function C takes the number of shoot days as its input and returns the modeled production cost.

Every valid input has exactly one output.

Example:

`C(3) = 1800 + 420(3)`

`C(3) = 3060`

Interpretation:

After three filming days, the modeled production cost is $3,060.

Make the relationship explicit:
- Input: number of filming days.
- Function rule: initial cost plus daily cost.
- Output: total production cost.

### Activity 2 — Evaluate the Function

Give students a collection of function questions.

For:

`C(d) = 1800 + 420d`

Ask:
- What is C(0)?
- What is C(2)?
- What is C(5)?
- What is C(8)?

Correct answers:
- C(0) = 1800.
- C(2) = 2640.
- C(5) = 3900.
- C(8) = 5160.

Students must substitute the input and interpret the result.

### Activity 3 — Multiple Production Functions

Introduce a second function:

`S(h) = 600 - 40h`

This returns the remaining free storage after h hours of filming.

Ask:

`S(5) = ?`

`S(5) = 600 - 40(5)`

`S(5) = 400 GB`

Now introduce a third function:

`E(h) = 120 + 90h`

Where E represents the modeled editing cost in credits.

Students should evaluate multiple functions and distinguish their inputs and outputs.

### Activity 4 — Is It a Function?

This is an important conceptual activity.

Show relationships from the film production process.

**Example A: Shoot day → total production cost**

Each number of shoot days has one modeled total cost.

This is a function.

**Example B: Unique clip ID → clip duration**

Each clip ID has one duration.

This is a function.

**Example C: Shoot day → duration of every individual clip recorded that day**

A single day may contain multiple clips with different durations.

For example:

`(1,12), (1,18), (1,24), (2,15)`

This is not a function if x represents shoot day and y represents the duration of an individual clip.

The same x-value has multiple y-values.

Explain that multiple inputs may share the same output, but a single input cannot have multiple outputs in a function.

### Activity 5 — The Vertical Line Test

Show a collection of graphs.

Ask the student whether each graph represents a function.

The student should move a vertical test line across the graph.

If the vertical line intersects the relationship more than once at the same x-value, the graph is not a function.

Include:
- Standard linear functions.
- Horizontal lines.
- Vertical lines.
- A curved non-function relation.

Use the production scenarios to explain the results.

### Activity 6 — Function Notation in Context

Present short production statements.

Examples:

- `C(4)` means the total production cost after four shoot days.
- `S(3)` means the remaining free storage after three hours of recording.
- `E(5)` means the modeled editing cost after five editor-hours.

Require students to translate between:
- Function notation.
- Verbal descriptions.
- Tables.
- Equations.
- Graphs.

### Activity 7 — Director's Dashboard Challenge

Build a final interactive dashboard.

The student selects a production function and supplies an input.

The dashboard displays:
- Input value.
- Function rule.
- Substituted expression.
- Output.
- Units.
- Real-world interpretation.

Require the student to calculate before revealing the output.

# PART IX — MATHEMATICAL QUALITY ASSURANCE

## 30. Automated calculation tests

Every example must have automated tests.

### Writing Linear Equations

Test:

`C = 420d + 1800`

At d = 3:

`C = 3060`

Slope and point:
- m = 420.
- Point = (3,3060).
- Equation = `C = 420d + 1800`.

Two points:
- (1,2220).
- (5,3900).
- Slope = 420.
- Intercept = 1800.

Table values:
- 0 → 1800.
- 1 → 2220.
- 2 → 2640.
- 3 → 3060.
- 4 → 3480.
- 5 → 3900.

### Slope-Intercept Form

Test:

`C = 420d + 1800`

- Slope = 420.
- Y-intercept = 1800.

Test:

`C = 300d + 2000`

- Slope = 300.
- Y-intercept = 2000.

Test equation conversion:

`2C - 840d = 3600`

Expected:

`C = 420d + 1800`.

### Point-Slope Form

Test:

`C - 3060 = 420(d - 3)`

Expected equivalent slope-intercept form:

`C = 420d + 1800`.

Test:

`E - 1200 = 150(h - 4)`

Expected equivalent slope-intercept form:

`E = 150h + 600`.

### Graphing Linear Equations

Test:

`C = 420d + 1800`

- Y-intercept: (0,1800).
- Slope: 420.

Test:

`S = 600 - 40h`

- Y-intercept: (0,600).
- X-intercept: (15,0).

Test:
- `y = 700`: horizontal.
- `x = 4`: vertical and undefined slope.

### Domain and Range

Test:

`C(d) = 1800 + 420d`, with `0 ≤ d ≤ 8`.

Expected:
- Domain: [0,8].
- Range: [1800,5160].

Test:

`S(h) = 600 - 40h`, with `0 ≤ h ≤ 15`.

Expected:
- Domain: [0,15].
- Range: [0,600].

Test discrete versus continuous input handling.

### Function Notation

Test:

`C(d) = 1800 + 420d`

- C(0) = 1800.
- C(2) = 2640.
- C(5) = 3900.
- C(8) = 5160.

Test:

`S(h) = 600 - 40h`

- S(5) = 400.

Test:

`E(h) = 120 + 90h`

- E(5) = 570.

Test function relationships:
- One input with one output: function.
- One input with multiple distinct outputs: not a function.
- Multiple inputs sharing one output: can still be a function.

## 31. Common misconception testing

Test specifically for:
- Confusing slope with y-intercept.
- Interpreting the slope as the starting cost.
- Writing the slope as a reciprocal.
- Incorrectly substituting into a two-point equation.
- Sign errors in point-slope form.
- Incorrect distribution when converting forms.
- Graphing slope in the wrong direction.
- Confusing x- and y-intercepts.
- Treating a vertical line as a function of x.
- Assuming domain and range are always all real numbers.
- Ignoring practical input constraints.
- Treating discrete schedules as continuous without explanation.
- Treating function notation as multiplication.
- Thinking that every relation is a function.
- Assuming multiple inputs cannot share an output.
